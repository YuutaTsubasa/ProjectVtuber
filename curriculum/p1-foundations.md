# P1 · 基礎（Day 1–60）

**目標**：從完全不會開 Blender，到能不看教學獨立做出一個小物件並算圖。

**主教材**：Blender Guru「Donut 5.0」系列 → Blender 5.0 完整初學課程
官方入口（含所有影片連結、快捷鍵表、Unstuck Yourself Guide）：
<https://www.blenderguru.com/posts/blender-donut-v5-tutorial>

## 時間校準（重要）

**影片長度 ≠ 你要花的時間。** 零基礎跟著操作，實際耗時是影片長度的 **2–3 倍**。
一支 30 分鐘的影片會吃掉你一整天的額度，這是正常的，不是你太慢。

如果一天做不完一個任務，**就停在那裡**，隔天接著做，不要熬夜趕完。
任務數會自動往後推，這在設計裡是允許的。

## 節奏

```
學 → 消化 → 學 → 學 → 消化 → 彈性日
```

「消化日」= 關掉教學，憑記憶重做一次前一天的內容。做不出來就是沒學會，
這時候回去查、重看，比往前衝有價值得多。

# Day 1 — 環境準備與視角操作

**今天學什麼**
安裝正式版 Blender、認識介面、把「視角操作」練成肌肉記憶。

**為什麼先做這個**
你目前裝的是 **5.2.0 Alpha**（2026-03 build）。Alpha 版 UI 會變、addon 會壞，
不能拿來當一年課程的基準。另外，視角操作是唯一一個你之後每天都會用幾百次的東西，
不熟的話後面每個任務都會卡。

**動手**
1. 到 <https://www.blender.org/download/> 下載**正式版**（不是 alpha/beta），安裝。
   舊的 Alpha 可以留著不管，但之後一律用正式版。
2. 開啟後，把官方入口頁的**快捷鍵表（cheat sheet）**下載下來，放手邊。
3. 練習視角操作，直到不用想：
   - 旋轉視角、平移視角、縮放
   - 數字鍵盤 1 / 3 / 7 切前 / 側 / 上視圖（筆電沒數字鍵盤的話，
     Preferences → Input → 勾「Emulate Numpad」，改用主鍵盤數字列）
   - 選取物件、移動 (G)、旋轉 (R)、縮放 (S)
4. 在場景裡放至少 **3 個不同種類**的基本物件（例如方塊、球、圓柱），
   擺在明顯不同的位置與大小。

**驗收條件**
- 你能在不看筆記的情況下，30 秒內切到前視圖、選到指定物件、把它移到別的地方。
- 存檔為 `work/p1/day01.blend`，檔案裡有 ≥3 個 mesh 物件，位置與尺寸各不相同。

**回報時告訴我**
你裝的正式版版本號（我會記進 STATUS.md，之後所有教材相容性都以它為準）。

# Day 2 — 甜甜圈本體

**今天學什麼**
跟著 Donut 系列做出甜甜圈的形狀。過程中會第一次碰到：
Edit Mode、Shade Smooth、修改器（Subdivision Surface）、Loop Cut。

**動手**
從官方入口頁開始跟第一支影片，做到**甜甜圈本體成形**為止。

**先講一件會嚇到你的事**：加上 Subdivision Surface 之後模型會變得又圓又醜，
這是正常的。修改器是「非破壞性」的——它不改變你原本的網格，只改變顯示結果，
隨時可以關掉或刪掉。

**驗收條件**
- 存檔為 `work/p1/day02.blend`
- 檔案裡有一個 torus（甜甜圈）mesh，帶有 **Subdivision Surface 修改器**
- 我會用 `inspect_blend.py` 檢查修改器堆疊

**做不完就停**
這支影片對零基礎來說很可能超過一天的額度。停在哪裡都可以，
回報時告訴我你做到哪個步驟，隔天接著做。

# Day 3 — 消化日：重做甜甜圈本體

**今天做什麼**
**關掉教學影片**，開一個新檔，憑記憶把 Day 2 的甜甜圈本體重做一次。

**為什麼**
跟著影片做只證明你「能跟上」，不證明你「會做」。這一天的目的是找出你以為會、
其實不會的地方——那才是真正需要補的。

**卡住怎麼辦**
卡住是**預期中的**，不是失敗。順序是：
1. 先自己想 2 分鐘
2. 想不出來就查快捷鍵表
3. 還是不行才回去看影片，而且只看卡住的那一段

**回報時告訴我**：你卡在哪幾個步驟。這比「做完了」有用得多，
我會據此判斷要不要在後面補強。

**驗收條件**
- 存檔為 `work/p1/day03.blend`
- 內容與 Day 2 相當（torus + Subdivision Surface）
- **不要**複製 day02.blend

# Day 4 — 讓甜甜圈不再完美

**今天學什麼**
Proportional Editing（比例編輯）——把工整的幾何體變成有手感的有機形狀。

這是 3D 的一個核心觀念：**完美對稱看起來很假**。之後做角色時，
這個「刻意破壞規律」的技巧會一直用到。

**動手**
跟教學把甜甜圈捏歪、壓扁、做出不規則感。

**驗收條件**
- 存檔為 `work/p1/day04.blend`
- 甜甜圈明顯不再是完美的環形（我會比對頂點座標的分布）

# Day 11 — 材質入門

**今天學什麼**
Shader Editor、Principled BSDF、Base Color / Roughness / Metallic 的意義。

**這一天對你的目標特別重要**：Vtuber 模型的臉部品質有很大一部分是材質決定的，
而 NiloToon（你最終要用的卡通渲染）也是建立在對材質參數的理解上。

**驗收條件**
- 存檔為 `work/p1/day11.blend`
- 甜甜圈本體與糖霜各有**不同的材質**
