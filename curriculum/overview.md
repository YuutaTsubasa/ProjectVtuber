# 課程總表

## 核心原則

1. **先學會使用 Blender，再學角色製作。**
2. **作品教學是整合練習，不是課程骨架。**
3. **Transfer > Memorization**：學到功能後，要換題目確認能否自行選用。
4. **Day N 是完成的第 N 個學習任務。** Flex / Rest Day 不編號。
5. **前期作品可以丟掉。** 最終 VTuber 到 P3 才正式開始。
6. **驗收能力，不驗收影片進度。**

## P1 — Blender 基礎（Day 1–60）

建立 Viewport、Transform、Edit Mode、Modeling、Modifier、Material、Light、Camera、Render、UV 的操作直覺。

前 14 個任務為新手村；約 Day 15 才進入 Donut 或同級完整 beginner project。

## P2 — 建模紮實化（Day 61–150）

Box / organic modeling、topology、edge flow、retopology、UV、texture，以及開始理解 deformation-friendly topology。

Topology 是 Rig / Weight / Shape Key 的重要基礎，但不是所有後續問題的唯一原因。課程同時會建立對 deformation、shading 與 mesh density 的判斷。

畢業：完成一顆拓樸乾淨、可繼續做角色練習的頭部（不是最終角色）。

## P3 — Character（Day 151–240）

Anime proportion、head、eyes、hair、body、hands、costume、accessories、character materials。

這時才正式開始最終 VTuber，避免把第一個零基礎作品變成捨不得重做的技術債。

畢業：完整原創角色 mesh。

## P4 — VTuber（Day 241–312）

Armature、weight painting、IK 基礎、facial deformation、blink、lip sync、ARKit 52 shape keys、hair/accessory physics、VRM / Unity integration、iPhone tracking。

畢業：角色能在目標 Unity 專案中由 iPhone 臉部追蹤實際驅動。

## 學習循環

推薦節奏不是固定「學一天、重做一天」，而是：

**Learn → Guided Practice → Transfer Quest → Review → Integration Project**

Transfer Quest 故意更換物件。例如學 Extrude 時可以先做杯子，下一題改成低模劍；能在不同問題中自行選擇 Extrude，才代表概念開始內化。

## 時間

每個任務預估 30–60 分鐘，但任務完成度優先於日期。做不完就下次繼續，不為了維持連續打卡而趕工。
