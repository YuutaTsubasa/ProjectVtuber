01為什麼今天要學這個

Day 3 你把 Cube 底部的四個角落往下拉，長出了桌腳。但仔細想一下那件事的本質：你沒有做出任何新的面，只是把原本就存在的面搬到別的位置，旁邊的側面被動地被拉長了。

今天的杯子用那一招做不出來。杯子需要杯壁——一圈原本不存在的幾何。你沒辦法靠搬移既有的面變出它，因為圓柱的頂面就只有那一個面，把它往下壓只會得到一個矮圓柱，不會得到一個有內部空間的容器。

你需要的是一個能「從這個面再生一份出來，並且用側面把新舊兩份接起來」的操作。這就是 Extrude 在解決的問題：需要更多幾何的時候，從既有的地方長出來，而不是另外加一個物件塞進去。

還有一件事跟著來：長出來之後要往哪個方向走，是你要決定的。Day 1 你在移動物件時學過把動作鎖在單一軸上——同一套想法今天會再用一次，只是這次被鎖住的是「新長出來的那一份往哪裡去」。

用一句話記住

需要從既有幾何延伸出形狀時，該想到的是 Extrude，不是「再加一個物件」。

02核心概念

Extrude ＝ 沿邊界長出一圈新幾何，再用側面接回去

Extrude 做的事可以拆成兩半：先沿著你選中那個面的邊界複製出一圈新的頂點與邊，用一圈新的側面把新舊邊界縫起來，並把選中的面本身接到新邊界上；然後才讓你移動它。理解這個順序很重要，因為它解釋了 Day 3 的「搬面」跟今天的「長面」差在哪——搬面會把旁邊既有的幾何拉變形，長面則是憑空多出一圈側面，原本的邊界原封不動留在原地。

常見誤解是把 Extrude 想成「把面往外拖」。如果只是拖，面數不會變；但 Extrude 之後模型確實變重了，因為多了一整圈側面。

再深入一點（選讀）

正因為「長出來」和「移動」是兩個階段，你可以只做前半段——長出來了但不移動。這在意外發生時是隱形錯誤（面看起來還是一個，但邊界多出一圈重複的頂點和一圈零面積的側面，肉眼看不出來），但今天做杯口時我們會故意用這個行為。同一個機制是坑還是工具，差別只在你知不知道自己在做什麼。

預設方向是「面自己朝的方向」，不是世界的上

啟動 Extrude 之後，新長出來的部分預設沿著這個面自己面向的方向走，而不是世界的垂直軸。頂面朝上時兩者剛好重合，所以你不會察覺；但一旦你對著一個斜面或側面 Extrude，它就會往斜的跑，那通常不是你要的。

要換方向，在 Extrude 進行中直接指定軸就好，這會蓋掉預設值。做杯子時你大部分時候會想明確鎖住垂直方向，而不是賭預設剛好對。

再深入一點（選讀）

選中多個面一起 Extrude 時，Blender 預設把它們當成一整塊區域往同一個方向長。另外有一種模式是讓每個面各自沿自己的方向長，出來的形狀完全不同。今天的杯子只會用到前者，知道有這回事就夠了。

杯壁的厚度，是兩次 Extrude 換來的

一個有厚度的杯子，在幾何上是「一個外殼 ＋ 一個從杯口往下凹的內部」，兩者之間夾著一圈環狀的杯口。很多人第一次做會卡在「內部要從哪裡來」，然後退回去加第二個小圓柱塞進去——那會得到兩個互不相關的物件，不是一個容器。

正確的思路是：先在杯口那個面上做出一圈邊，把它分成外圈與內圈，再把內圈往下推。這兩件事今天都只用 Extrude 加上你已經會的縮放就能完成。

再深入一點（選讀）

之後你會學到專門用來「向內縮一圈」的工具，一步就能取代今天的兩個動作。今天刻意用比較土的做法，是因為它會逼你看清楚面是怎麼被分出來的——先看懂機制，之後用快捷工具才不會變成背步驟。

05操作流程

每一步先看「要達成什麼」，自己試兩分鐘再展開詳解。展開不扣分，直接展開才會少學東西。

  1. 決定杯子從哪一個 primitive 開始，並想清楚它現在缺什麼

    杯子的外型接近哪一種內建形狀？先在腦中比對「它現在長什麼樣」跟「杯子該長什麼樣」，差的是哪一塊。

    展開詳細操作

    Shift+A ▸ Mesh ▸ Cylinder。加進來之後左下角面板可以改 Vertices（預設 32，維持即可）。

    圓柱現在是實心的：頂面是一整個面，沒有任何內部空間。缺的就是那個內部，以及圍住它的杯壁。

    順帶一提，這個頂面是一個 32 邊形，也就是所謂的 n-gon。今天不會對它做平滑或變形，所以它完全沒問題——n-gon 要到你之後想讓表面平滑、或要讓模型變形時，才會開始惹麻煩。

  2. 進到能改形狀的模式，並只選中杯口那一整個面

    今天全程只需要抓「面」這個粒度。選錯粒度的話，後面每一步都會怪怪的。

    展開詳細操作

    Tab 進 Edit Mode，按 3 切到 Face 選取模式。先 Alt+A 清空選取，再左鍵點圓柱的頂面，只有那一個面該是橘色的。

    從側視圖（Numpad 3）確認你選到的是頂面不是底面——從斜上方看很容易誤判。

  3. 讓杯口從「一整個面」變成「外圈 ＋ 內圈」

    你需要在同一個高度上多出一圈邊。想想有沒有辦法讓 Extrude 只做前半段——長出來，但不要移動。

    展開詳細操作

    按 E 之後不要動滑鼠，直接按 Esc（按右鍵也一樣）。新的幾何已經產生了：杯口邊界多出一圈新的頂點，和原本的邊界疊在同一個位置——這正是我們要的。

    接著在它還被選中的狀態下按 S 往內縮，左鍵確認。現在杯口上出現了一圈環狀的邊，中間就是等一下要往下挖的內圈。

    縮多少決定杯壁多厚。想精確一點就直接打數字：S 0.9 Enter。

  4. 把內圈往下推，做出杯子的內部空間

    這一步要明確指定方向，不要相信預設值。面朝上時看起來一樣，但養成習慣比較安全。

    展開詳細操作

    內圈還選著的狀態下按 E，接著按 Z 把方向鎖在世界的垂直軸上，往下拖，左鍵確認。想精確就打負數，例如 E Z -1.6 Enter（數字依你的圓柱高度調整）。

    注意不要挖穿底部。照上面的示範數字算：預設圓柱高 2，杯壁縮到 0.9 等於厚 0.1，往下 1.6 之後底部還留 0.4——比杯壁厚一些是正常的，真實杯子的底部本來就比較厚，不必刻意調成一樣。挖太深或太淺都不用重做，按 F9 叫回面板改距離即可。

  5. 從正交視角確認杯壁厚度與內部深度

    透視視角會騙人，而且從外面根本看不到內部，得換個方式檢查。

    展開詳細操作

    Numpad 1（前）與 Numpad 3（側）各看一次，確認兩件事：杯口那一圈的寬度從各個角度看是否一致，以及你往下挖的距離有沒有超過圓柱的高度。

    想直接看穿的話，用 Day 3 那個 X-Ray（Alt+Z）從側面看最快，確認底部沒有被挖破。

  6. 遷移挑戰：不看步驟，用 Extrude 做一把非常簡單的低模劍

    這一步沒有詳解可以展開。想想一把劍由幾段組成、每一段跟前一段的差別是什麼，然後從一個 Cube 開始，一段一段長出去。做不出來就記下卡在哪裡，回報時討論。

  7. 回到 Object Mode，把兩個成品都存到指定路徑

    兩個 Quest 放在同一個檔案裡就好。存檔前順便從外面看一眼整體比例。

    展開詳細操作

    Tab 回到 Object Mode，Ctrl+S 存到 work/p1/day04.blend。

    杯子和劍放在同一個場景、擺開一點不要重疊即可，不需要分成兩個檔案。

07卡住了？

照症狀找，先自我診斷，答案在第二層。

按了 Extrude 好像什麼都沒發生，但模型變得怪怪的

你是不是在動作進行到一半時按了 Esc 或右鍵？想一下那個取消掉的到底是「長出來」還是「移動」。

還是不行，看答案

Esc 取消的只有移動；新的幾何已經產生了，邊界多出一圈重複的頂點和一圈零面積的側面，和原本的疊在同一個位置。如果那不是你要的，Ctrl+Z 退一步就乾淨了。

已經做了別的操作、退不回去的話，全選之後在 Mesh 選單裡找 Merge ▸ By Distance，把重疊的點合併掉。

Extrude 出來的方向不是我要的，往斜的跑

這個面朝向哪裡？Extrude 預設不是沿著世界的軸，而是沿著另一個東西。

還是不行，看答案

預設沿的是這個面自己朝的方向。在 Extrude 進行中直接按 Z（或 X / Y）就會改成沿世界軸；再按一次同一個鍵會切回面自己的方向。

這跟 Day 2「軸鍵連按兩次換一組軸」是同一條規則，只是這次換的對象從物件變成面。

把杯口縮小的時候，整個杯子跟著變小

兩件事要確認：你現在在哪個模式？還有你選中的到底是一個面，還是整個 mesh？

還是不行，看答案

在 Object Mode 縮放會作用在整個物件——這正是 Day 3 那條「改物件 vs 改 mesh」的界線。確認左上角顯示的是 Edit Mode，按 3 切到 Face 模式，只選中杯口那一個面再縮。

如果在 Edit Mode 還是整個變小，多半是不小心按到 A 全選了，先 Alt+A 清空重來。

內部挖下去之後，杯子從底部穿出來了

你往下移動的距離，跟圓柱本身的高度比起來如何？

還是不行，看答案

挖的距離超過了「圓柱高度減去你想留的底部厚度」。不用重做——按 F9 叫回 Adjust Last Operation 面板，把 Move Z 往 0 的方向調，例如 -2.0 改成 -1.4。它是負值，所以「調小」會挖得更深，方向剛好相反。

中間已經做了別的操作、面板叫不回來，就 Ctrl+Z 退回去重挖。

08常見錯誤

常見做法為什麼有問題改成
另外加一個小一點的圓柱塞進去當「內部」 那是兩個互不相關的物件，不是一個有厚度的容器；之後上材質、算圖、匯出都會各走各的 從同一份幾何用 Extrude 長出內部
Extrude 完按了 Esc，以為沒成功又按一次 E 會疊出兩層重疊的幾何，肉眼看不出來，但之後要平滑或變形時就會出現破面 Esc 只取消移動；不確定就 Ctrl+Z 退乾淨再來一次
在 Object Mode 按 Extrude 的鍵 Extrude 是 mesh 層級的操作，在 Object Mode 不會有任何反應 先 Tab 進 Edit Mode——這就是 Day 3 那條界線的實際應用
杯子做完就想加把手、加雕花 curriculum 明寫「簡單杯子/容器」，今天驗的是你會不會主動想到 Extrude 杯子收工，時間留給 Quest B 的劍——那才是今天真正的考題
