01今天做什麼

從 Cube 做一張非常簡單的桌子

從 Cube 開始做一張非常簡單的桌子。

重點不是桌子，而是理解「改物件」與「改 mesh」是兩件不同的事。桌子醜沒有關係，分不清楚模式才是今天沒過。

02為什麼要學這個

Day 2 你把現成的形狀排在一起。但桌子不是任何一個 primitive 的形狀——沒有哪個內建物件長得像「一個板子加四隻腳」。今天第一次要動到形狀本身。

問題是這樣的：一個 Cube 只有 8 個點、6 個面。桌面可以由它壓扁而來，但四隻腳呢？你需要能夠只抓住這顆 Cube 的一部分，把那一部分拉到別的地方去，而其餘部分不動。這件事在 Day 2 的 Object Mode 裡做不到——在那裡按 移動，整個物件會一起走。

所以 Blender 把「改物件」和「改 mesh」分成兩個模式。今天真正要弄懂的是這條界線在哪裡，以及為什麼同一個按鍵在兩邊的意義完全不同。

用一句話記住

Object Mode 決定「這個東西在哪」，Edit Mode 決定「這個東西長什麼樣」。桌子只是拿來驗證你分得清楚的載體。

03動手前要知道的

只有這些是動手前非知道不可的。其餘概念放在會用到它的那一步裡，到時候再讀。

同一顆 Cube，兩種「改」

在 Object Mode 把 Cube 壓扁，你改的是這個物件的縮放值——mesh 裡那 8 個點的相對位置其實沒變，只是整個被壓縮著顯示。在 Edit Mode 把上面 4 個點往下拉，你改的是 mesh 資料本身，點真的移動了。畫面上看起來可能一樣，但它們是兩件不同的事。

再深入一點（選讀）

這條界線今天只要能分辨就好，但它之後會一直回來找你：物件層級的縮放會影響很多後續運算，而 mesh 層級的修改不會。現在先養成一個習慣——動手之前先問自己「我要改的是這個東西的擺放，還是它的形狀」。

04操作流程

每一步先看「要達成什麼」，自己試兩分鐘再展開詳解。展開不扣分，直接展開才會少學東西。

  1. 先想清楚：桌子的哪些部分需要新的幾何？

    一個 Cube 只有 8 個點、6 個面。對照一下桌子的樣子，哪一部分現在就做得出來，哪一部分還缺東西？

    展開詳細操作

    桌面可以由 Cube 直接壓扁而來，不需要新增任何幾何。四隻腳不行——底部現在是一整個面，你無法只抓住它的四個角落。

    所以今天的順序是：先把底部切細，再選角落，再把角落拉下去變成腳。想清楚這個順序再動手，比邊做邊猜快。

  2. 進到可以改形狀的模式，並確認你真的切過去了

    不要憑感覺。畫面和介面上都有明確的訊號告訴你現在在哪個模式。

    展開詳細操作

    選中 Cube，按 Tab。切進去之後 mesh 的點會顯示成小圓點（選中是橘色、未選是黑色），畫面左上角的模式下拉選單也會從 Object Mode 變成 Edit Mode。

    如果按 Tab 沒反應，多半是滑鼠不在 3D Viewport 上——Blender 的快捷鍵看的是游標在哪個區域。

  3. 把三種選取粒度各按一次，感受差別

    不要急著做桌子。先各按一次，看看畫面上被高亮的東西有什麼不同。

    Vertex / Edge / Face 是三種抓法，不是三種東西（選讀）

    點、邊、面不是各自獨立存在的三種零件，而是同一份幾何的三種選取粒度。三個點圍起來就有一條條邊，邊圍起來就有面。切換選取模式不會改變模型，只改變你這一刻能抓住什麼。常見誤解是以為「要先切到面模式，模型才有面」。

    要挪動一個角落 → 用點最直接。要把一整圈邊往某方向推 → 用邊。要把一整塊區域整片移動 → 用面。選不到想要的東西時，先問「我現在的抓法對嗎」，通常比亂點有效。

    展開詳細操作

    1 = Vertex（點）、2 = Edge（邊）、3 = Face（面）。在每個模式下都點一下 Cube 的同一個角落，觀察選中的範圍。

    注意切換模式時選取會自動轉換：在 Face 模式選一個面，切到 Vertex 模式會變成那個面的 4 個點被選中。它們描述的是同一塊幾何。

  4. 把 Cube 的面切細，讓底部出現可以單獨選取的角落

    目標是讓底部從「一個大面」變成「九個小面」，四個角落才會獨立出來。

    想只動一部分，得先讓那一部分存在（選讀）

    Cube 的底部只有一整個面。你沒辦法「只選底部的四個角落」，因為那四個角落在幾何上還不是獨立的面——它們就是同一個面。要做出四隻腳，得先把那個大面切成更多小面，才有東西可以單獨選取、單獨拉開。

    這是建模最基本的循環之一：需要更多控制點 → 先增加幾何 → 再選取 → 再變形。今天用最簡單的切法把面均分。之後會學到更精準的切法，但思路是同一個。

    展開詳細操作

    先 A 全選，然後在 Viewport 裡按右鍵 ▸ Subdivide。

    預設只切一刀，不夠。切完之後看畫面左下角展開的 Subdivide 面板，把 Number of Cuts 改成 2——每個面就會變成 3×3。這個面板只在你做下一個動作前有效。不小心點掉了不用 Undo 重切——按 F9 會在滑鼠位置彈回同一個面板（Adjust Last Operation）。

  5. 只選出底部的四個角落

    從正面選很容易連旁邊或背面的面一起抓到。換一個角度看會輕鬆很多。

    展開詳細操作

    Ctrl+Numpad 7 切到底視圖（沒有 Numpad 就點 Gizmo 的 −Z 空心球，或 View ▸ Viewpoint ▸ Bottom），3 切到 Face 模式。先 Alt+A 清空選取，再左鍵點第一個角落的面，其餘三個用 Shift+左鍵加選。

    選好之後轉回透視角度確認一下——只有底部四個角該是橘色的。如果連上面也選到了，多半是開了 X-Ray（穿透選取），關掉它就只會選到看得見的面。

  6. 把那四個面往下拉，長出四隻腳

    你不需要新增任何東西。把已經存在的面移到它該去的位置，腳自然就出現了。

    展開詳細操作

    G Z 往下拖，左鍵確認。側面的幾何會被一起拉長，形成四隻腳。

    覺得腳太粗，在四個面還選著的狀態下按 S 縮小；只想在水平方向變細就用 S Shift+Z（除了 Z 以外的方向縮放）。

  7. 調整桌面的厚度，並說得出你是在哪個模式做的

    這一步兩個模式都做得到，但它們改的東西不一樣。今天的重點就在這裡——做之前先決定，做完要能解釋。

    展開詳細操作

    Edit Mode 的做法：選中桌面上半部的點或面，G Z 往下壓。mesh 真的被改變了。

    Object Mode 的做法：Tab 回去，S Z 壓扁。這改的是物件的縮放值，mesh 沒動——而且會連四隻腳一起壓扁。

    今天兩種都允許，但你要能說出剛才選了哪一種、為什麼。這就是第 08 節會問你的事。

  8. 回到 Object Mode，存到指定路徑

    存檔前先切回去，順便從外面看一眼整體比例。

    展開詳細操作

    Tab 回到 Object Mode，Ctrl+S 存到 work/p1/day03.blend。

05卡住了？

照症狀找，先自我診斷，答案在第二層。

按了鍵沒反應，或同一個鍵好像變了意思

先確認兩件事：你現在在哪個模式？滑鼠游標在哪個區域？Blender 的快捷鍵同時受這兩者影響。

還是不行，看答案

看畫面左上角的模式下拉選單確認目前是 Object 還是 Edit Mode，Tab 可切換。另外 Blender 的快捷鍵作用於游標所在的編輯器——游標飄到 Outliner 或 Properties 上時，按 1/2/3 當然不會切換選取模式。把游標移回 3D Viewport 再按。

切細之後整顆 Cube 變圓了，不是我要的

你用的是 Edit Mode 右鍵選單裡的那個 Subdivide，還是在 Properties 裡加了一個東西上去？這是兩個名字很像但完全不同的功能。

還是不行，看答案

變圓表示你加到的是 Subdivision Surface（一個 Modifier），不是 Edit Mode 的 Subdivide（一個操作）。到右側 Properties 的扳手圖示分頁，把那個 modifier 刪掉，再回 Edit Mode 全選、右鍵 ▸ Subdivide。

想只選底部四個角，卻連旁邊或背面的面一起選到

兩個方向檢查：你現在的選取粒度對嗎？還有，你的視角能不能真的看見你要選的那四個面？

還是不行，看答案

先按 3 確認在 Face 模式，Alt+A 清空重來，並用 Ctrl+Numpad 7（或 Gizmo 的 −Z 空心球）轉到底視圖。如果點一個面卻連背面也選到，是 X-Ray（穿透選取）開著——在畫面右上角那排圖示裡把它關掉，或按 Alt+Z 切換。

要拉桌腳，結果整個 Cube 一起移動

整個物件一起動，通常代表你操作的層級不對。想想你這時候是在改「物件」還是在改「mesh」。

還是不行，看答案

你還在 Object Mode——那裡的 G 移動的是整個物件。按 Tab 進 Edit Mode，選好那四個面之後再 G。這正是今天要分清楚的那條界線。

06常見錯誤

常見做法為什麼有問題改成
在 Object Mode 壓扁，以為改到了形狀改到的是物件的縮放值，mesh 本身沒變，而且會連桌腳一起壓扁要改形狀就 Tab 進 Edit Mode 動點或面
把 Edit Mode 的 Subdivide 當成 Subdivision Surface名字像，但一個是切細幾何、一個是 Modifier 平滑整體，結果完全不同今天只用 Edit Mode 全選後右鍵的 Subdivide
切完面才發現刀數不夠，直接再切一次在已經切過的面上再切，會得到不均勻的密度，之後更難選先按 F9 叫回面板改 Number of Cuts；已經做了別的操作才用 Ctrl+Z 退回重切
想把桌子做得好看，開始加倒角和細節curriculum 明寫「重點不是桌子」，今天驗的是分不分得清兩個模式桌面加四隻腳就收工，時間留給第 08 節的三個問題
