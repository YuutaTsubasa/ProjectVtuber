01今天做什麼

三個 primitive，三種姿態

加入 Cube、Sphere、Cylinder，將三者移到不同位置、旋轉角度與尺寸。

不需要排得好看，也不需要有主題。今天要驗的是你能不能指哪打哪，不是美感。

02為什麼要學這個

Blender 的畫面，是一個三維空間被壓平投影到二維螢幕上的結果。你看到方塊「往右移動」，它在空間裡可能其實是往前、往後，或斜著跑。眼睛看到的位移，不等於實際發生的位移。

這件事在今天只是有點煩，但到了做角色、對稱、對齊零件的時候會變成真正的災難——你會做出一個左右不對稱、但從某個角度看起來剛好正確的東西。所以第一天不建模，先處理更根本的問題：我怎麼確定自己正在看哪個方向，以及我正在往哪個軸移動。

Transform（移動 / 旋轉 / 縮放）則是 Blender 裡使用頻率最高的一組操作。之後每一天、每一個階段，你都會用到它們。今天把手感練起來，後面所有課都便宜。

用一句話記住

先能穩定地「看」，才能穩定地「改」。

03動手前要知道的

只有這些是動手前非知道不可的。其餘概念放在會用到它的那一步裡，到時候再讀。

選取決定了「作用對象」

Blender 幾乎所有操作，作用的都是目前被選取的東西，而不是滑鼠底下的東西。按 G 之前沒有選到任何物件，就什麼事都不會發生。

被選取的物件有橘色外框；其中顏色最亮的那一個是 active（作用中）物件，多選時它會是某些操作的參考基準。

常見誤解：把滑鼠移到某個物件上就以為它被選中了。要按左鍵。

04操作流程

每一步先看「要達成什麼」，自己試兩分鐘再展開詳解。展開不扣分，直接展開才會少學東西。

  1. 確認並記下你的 Blender 版本（今天一定要做）

    版本資訊不用去網路上找，Blender 自己就會告訴你。抄下來的版本號會記進 progress/STATUS.md，之後整個 P1 的教材選擇都以它為準。

    展開詳細操作

    啟動畫面（Splash Screen）右下角會顯示版本；關掉了就從 Help ▸ About Blender 看。抄下完整字串，例如 4.5.3 LTS。

    再到 blender.org/download 對照目前官方 Stable 是哪一版。如果你裝的是 alpha 或 beta，換成 Stable 再開始——教材與 addon 的相容性都以 Stable 為基準。

  2. 把「轉、移、縮」三種視角操作各做十次

    這一步沒有成果物，純粹是讓手記住。三個動作都跟中鍵有關。

    展開詳細操作

    中鍵拖曳 = 繞著場景轉；Shift+中鍵拖曳 = 平移畫面；滾輪 = 拉近拉遠。刻意把畫面轉到很怪的角度，再自己轉回來。

    沒有中鍵或用觸控板：Edit ▸ Preferences ▸ Input ▸ 勾選 Emulate 3 Button Mouse，之後 Alt+左鍵拖曳就等於中鍵拖曳。

  3. 練習切換三個主要正交視角，並觀察畫面左上角的變化

    切換的時候看左上角文字，它會直接告訴你現在站在哪個方向、是不是正交。

    三個軸，以及正交視角（選讀）

    Blender 的世界有三個軸：X（紅）、Y（綠）、Z（藍），而 Z 是「上」。畫面左下角永遠有一組小座標軸告訴你目前的朝向。

    預設的透視（Perspective）視角比較像人眼，好看，但會讓平行線看起來不平行——拿來判斷「有沒有對齊」很不可靠。正交（Orthographic）視角沒有透視變形，是對齊專用的視角。

    常見誤解：以為「前視圖」就是「我現在看到的正面」。它其實是一個固定的方向（從 −Y 看向原點），跟你剛才把畫面轉到哪裡無關。

    Blender 採 Z-up，是沿用工程與 CAD 的慣例；Unity 則是 Y-up。之後匯出模型時會遇到軸向轉換的問題，但那是 P4 的事，今天完全不用管。

    展開詳細操作

    Numpad 1 前視（從 −Y 看）、Numpad 3 右視（從 +X 看）、Numpad 7 上視（從 +Z 看）。左上角會顯示 Front Orthographic 之類的字樣。

    沒有 Numpad 的話，點右上角 Gizmo 的 −Y（前）、+X（右）、+Z（上）三顆球，效果一樣；View ▸ Viewpoint 選單裡也都有。

    接著按幾次 Numpad 5（沒有 Numpad 就用 View ▸ Perspective/Orthographic）在 Perspective / Orthographic 之間切換，注意方塊的邊在兩種模式下的差別——這就是透視會騙人的地方。

  4. 在場景中加入 Cube、Sphere、Cylinder

    新物件會出現在一個固定的地方，所以三個會疊在一起。這是正常的，等一下再分開。

    展開詳細操作

    Shift+A ▸ Mesh ▸ Cube / UV Sphere / Cylinder，加三次。

    新物件出現在 3D Cursor 的位置（預設在原點），所以三個會互相穿插。今天不用處理 3D Cursor，加完直接移開就好。

  5. 讓三個物件各自分開站好

    自由拖曳很容易讓物件在你沒注意的軸上偏掉。想辦法讓它只往一個方向動。

    Transform 三兄弟：G / R / S（選讀）

    移動（Grab）、旋轉（Rotate）、縮放（Scale）。三個的操作語法完全一樣：按下按鍵 → 進入該模式 → 移動滑鼠改變數值 → 左鍵確認、右鍵或 Esc 取消。

    進入模式之後可以再按 X / Y / Z 把動作鎖在單一軸上，也可以直接打數字輸入精確值。學會這一組語法，等於一次學會三個工具。

    常見誤解：以為要先去左邊工具列點選「移動工具」才能移動。那些工具列按鈕是另一種操作方式，不是前提。

    取消（Esc）和 Undo（Ctrl+Z）不一樣。取消是「這次操作根本沒發生」，Undo 是「已經發生了，我要退回上一步」。操作到一半發現不對，用取消比較乾淨。

    展開詳細操作

    左鍵點選一個物件 → G → 按 X（或 Y）鎖軸 → 移動滑鼠 → 左鍵確認。

    想要精確一點：G X 2 Enter，直接沿 X 軸位移 2 公尺。切到 Numpad 7 上視圖（或點 Gizmo 的 +Z 球）來擺位會更好判斷。

  6. 給每個物件不同的旋轉角度與尺寸

    不用學新語法。旋轉和縮放跟你剛才做的移動是同一套操作語法，鎖軸和打數字都一樣。

    展開詳細操作

    R Z 45 Enter = 繞 Z 軸轉 45 度。S 0.5 Enter = 整體縮成一半。S Z 2 Enter = 只在 Z 方向拉長兩倍。

    三個物件要看得出「位置不同、角度不同、大小不同」。做壞了 Ctrl+Z，操作到一半後悔就 Esc。

  7. 存到指定路徑

    路徑和檔名都要正確，之後的自檢會照這個路徑找檔案。

    展開詳細操作

    Ctrl+S（第一次會跳出 Save As）→ 存到 work/p1/day01.blend。存好之後視窗標題列會顯示檔名。

05卡住了？

照症狀找，先自我診斷，答案在第二層。

物件不見了，畫面一片空白

先分辨是哪一種：物件真的被移到很遠的地方，還是只是視角轉開了？右上角的 Outliner 清單裡，物件名稱還在不在？

還是不行，看答案

名稱還在 Outliner，就代表物件存在，是視角問題。在 Outliner 點一下它的名字選取，然後把滑鼠移回 3D 畫面按 Numpad .（等同 View ▸ Frame Selected），畫面會直接飛過去。

想一次看到全部場景：按 Home。

按了 G 之後物件跟著滑鼠亂飛，停不下來

Transform 是「按下按鍵就進入模式」，在模式裡滑鼠移動本身就是輸入。你有做出「結束這個模式」的動作嗎？

還是不行，看答案

左鍵或 Enter = 確認並套用；右鍵或 Esc = 取消，物件回到原位。取消比事後 Undo 乾淨，因為它根本沒有產生一步歷史紀錄。

我的鍵盤沒有 Numpad，切不了正交視角

正交視角一定要透過 Numpad 嗎？想一想 Blender 有沒有提供替代設定，或是畫面上的圖形入口。

還是不行，看答案

用畫面右上角的座標軸 Gizmo：實心球是 +X／+Y／+Z，空心球是負方向。點 +X 到右視、−Y 到前視、+Z 到上視、−Z 到底視。或用 View ▸ Viewpoint 選單，六個方向都在。鍵盤派可以按 ` 叫出視角圓盤選單。

Blender 確實有 Edit ▸ Preferences ▸ Input ▸ Emulate Numpad 這個設定，但別開——它會把主鍵盤的 1 2 3 一起吃掉，而 Day 3 起那三個鍵是切 Vertex／Edge／Face 選取模式用的。上面三條路都沒有這個副作用。

按了 G 但完全沒反應

Blender 的操作作用在「被選取的東西」上。你確定有選到嗎？另外，滑鼠游標當時停在哪個區域？

還是不行，看答案

兩個常見原因：一是沒有選取任何物件（物件沒有橘色外框）；二是滑鼠游標不在 3D Viewport 裡——Blender 的快捷鍵依游標所在的面板而定，游標停在 Outliner 上按 G 是不會移動物件的。

縮放之後總覺得哪裡怪怪的

你是等比例縮放，還是不小心只縮了單一軸？右側面板有一組數值可以直接告訴你答案。

還是不行，看答案

按 N 打開右側邊欄，看 Item ▸ Scale 的三個數字。三個都一樣 = 等比例；不一樣 = 你在某個軸上拉伸了。

今天不需要處理非等比縮放的後續影響，知道這組數字存在、之後會回來找它就好。

我的鍵盤沒有 Numpad（筆電常見）

不用開 Emulate Numpad——這門課有三條不需要 Numpad 的路，先用它們：

  1. 右上角的座標軸 Gizmo（最快）。三顆實心球是 +X／+Y／+Z、三顆空心球是負方向。點 +X 到右視、−Y 到前視、+Z 到上視、−Z 到底視。
  2. View ▸ Viewpoint 選單（最完整）。3D Viewport 左上角的 View 選單裡，六個方向都在，還會標出各自對應的 Numpad 鍵。
  3. `（鍵盤左上角那個重音符）會叫出一圈視角的圓盤選單，放開時選中哪個就切到哪個。習慣之後比 Numpad 還快。

表格裡另外兩個 Numpad 鍵也都在同一個 View 選單裡：Numpad 5 的透視／正交切換是 View ▸ Perspective/Orthographic，Numpad . 的聚焦到選取物件是 View ▸ Frame Selected。

為什麼不建議 Emulate Numpad：它會讓主鍵盤上方的數字列整排變成 Numpad，代價是那排數字原本的功能全被吃掉——包括 1 2 3。Day 3 開始那三個鍵是用來切 Vertex／Edge／Face 選取模式的，是天天都會按的核心操作。用一個三天後會反咬你的設定，去換一個 Gizmo 就能做到的事，不划算。
