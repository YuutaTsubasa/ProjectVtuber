01今天做什麼

用 primitive 組一個機器人或雪人

只使用 primitives 做一個簡單機器人或雪人。不要追求漂亮。

「不要追求漂亮」是課程原文，不是客套。今天驗的是你能不能安排零件，不是造型品味。

遷移挑戰

最後再加入一個你自己決定的零件，不照任何步驟。

這一段不提供步驟。做不出來就記下卡在哪裡，回報時討論。

02為什麼要學這個

Day 1 你已經能把一個物件搬到想要的位置。但真正的作品不會只有一顆球——它是一堆零件被安排在對的地方。零件一多，會冒出三個 Day 1 不存在的問題。

第一，新的零件會出現在哪裡？你按下新增之後，它不一定落在畫面中央，也不一定在原點。Blender 有一個明確的「放置點」在決定這件事，不知道它在哪，就會一直覺得物件亂跑。

第二，一模一樣的零件要怎麼來？機器人的兩隻手臂應該等長等粗。重新加一次再手動調到「看起來差不多」，永遠會差一點，而且改設計時要改兩次。

第三，「往上」是誰的上？當一個零件被你轉了 30 度，你叫它往上，它可能往斜的跑。這不是 Blender 壞了，是它在問你講的是世界的上，還是這個零件自己的上。

用一句話記住

今天不學新形狀，學的是「一批現成零件怎麼被安排成一個東西」。

03動手前要知道的

只有這些是動手前非知道不可的。其餘概念放在會用到它的那一步裡，到時候再讀。

Object Mode 是在排零件，不是在改形狀

今天全程待在 Object Mode。你在做的事情是「把現成的形狀擺到對的位置、調成對的大小」，不是去動它的點線面。另一個常見誤解是覺得零件要「合併成一個」才算完成——不需要，各自獨立的多個物件同樣是一個完整的模型。

再深入一點（選讀）

進 Edit Mode 改點線面是明天的事。今天刻意把手綁起來，是為了讓你先把「用簡單形狀組合出複雜東西」這件事練起來——這個思路在之後做角色時一樣有用。

04操作流程

每一步先看「要達成什麼」，自己試兩分鐘再展開詳解。展開不扣分，直接展開才會少學東西。

  1. 先決定做機器人還是雪人，並數出它由哪幾種形狀組成

    不用畫草圖。心裡能數出「幾顆球、幾個方塊、幾根柱子」就可以開始了。

    展開詳細操作

    雪人比較快：兩到三顆 UV Sphere 疊起來，加上兩顆小球當眼睛、一個細長的 Cylinder 當手臂。機器人零件多一點：Cube 當身體與頭、Cylinder 當四肢與脖子。

    建議控制在 5–8 個零件。太少練不到安排，太多會做不完。

  2. 確認新零件會生在你預期的位置

    新增的東西不是憑空出現在畫面中央。場景裡有一個小標記在決定落點，先確定它在原點。

    新物件出現在 3D Cursor，不是畫面中央（選讀）

    那個紅白相間的小圈圈就是 3D Cursor，它是 Blender 的「放置點」。你新增的每一個 primitive 都會生在它身上。常見誤解是以為新物件固定出現在世界原點——其實只要你不小心點過一次，它就搬家了，之後加的東西全部跟著歪。

    3D Cursor 除了決定新物件的位置，也可以當旋轉與縮放的中心點。今天用不到那個用法，只要記得「它在哪，新東西就生在哪」，以及怎麼把它送回原點就夠了。

    展開詳細操作

    找畫面中那個紅白虛線的小圈圈，就是 3D Cursor。按 Shift+C 會把它送回世界原點並把視角拉遠到看得見全部；如果你不想動到視角，改用 Shift+S 叫出 Snap 選單，選 Cursor to World Origin。

    順帶記住：在 Viewport 裡按 Shift+滑鼠右鍵 就會把 Cursor 移到該處——很多「物件為什麼跑到那裡」都是不小心按到這個。

  3. 放進最大的那一塊當身體

    先做最大的零件，後面所有零件的比例才有東西可以參考。

    展開詳細操作

    Shift+A ▸ Mesh ▸ 選 UV Sphere 或 Cube。

    加進來之後，畫面左下角會出現一個可以展開的 Add 面板，裡面能直接改半徑、大小、Segments。這個面板只在你做下一個動作之前有效。不小心把它收起來不用重加——按 F9 會在滑鼠位置彈回同一個面板（Adjust Last Operation），照樣可以改。

  4. 把重複出現的零件複製出來，而不是重新加一次

    兩隻手臂應該完全一樣。想想「先做好一隻」跟「加兩次各自調」哪一種能保證一致。

    Duplicate 不只是省時間，是保證一致（選讀）

    需要兩隻一樣的手臂時，正確做法是做好一隻再複製，而不是加兩次再各自調整。複製出來的副本尺寸、比例、旋轉都與原件完全相同，你只要負責把它移到對的位置。

    Blender 有兩種複製：一種產生獨立的副本，改了不會互相影響；另一種讓副本共用同一份 mesh 資料，改任何一個其他都會跟著變。今天兩種都可以用，但要知道自己用的是哪一種——不然之後改了一邊，另一邊沒動（或全部一起動）都會很困惑。

    展開詳細操作

    選好做完的那一隻，Shift+D 複製，接著直接打軸向把副本移開，例如 Shift+D X 2 Enter。複製完 Blender 就在等你移動，這時按左鍵或 Esc 會讓副本停在原地與原件重疊。

    要左右對稱的話，複製後打 S X -1 Enter 可以沿 X 軸鏡射。

    若你想「改一個、全部跟著改」，改用 Alt+D。今天兩種都可以，但要清楚自己用了哪一種。

  5. 處理「轉過角度的零件要怎麼移動」

    把一隻手臂轉斜之後，叫它往上，它會往斜的跑。先想想 Blender 這時候在問你什麼。

    Global 與 Local：「上」有兩個意思（選讀）

    Global 是世界的座標軸，永遠不動；Local 是物件自己的座標軸，會跟著它一起轉。零件沒轉過的時候兩者重合，所以 Day 1 感覺不到差別。一旦零件斜了，你就必須決定要沿哪一組軸移動。斜著長出來的手臂要往「自己的長度方向」延伸時，用的是 Local。

    除了這兩種，Blender 還有 Normal、View 等其他 orientation。原理都一樣：先決定「以誰為準」，再談方向。今天只要能分辨世界的軸和物件自己的軸即可。

    展開詳細操作

    先用 R 把手臂轉個角度，再試 G Z——它沿的是世界的 Z 軸。想沿手臂自己的方向，把軸鍵連按兩次：G Z Z。

    畫面上方中間的 Transform Orientation 下拉選單（預設 Global）顯示的就是目前以誰為準。連按兩次軸鍵等於臨時切到 Local，不會改變那個設定。

  6. 從幾個正交視角檢查比例與接合處

    正面看起來貼合的兩個零件，從側面看常常是一個在前、一個在後，中間空的。

    展開詳細操作

    Numpad 1（前）、Numpad 3（側）、Numpad 7（上）輪流看過一次；沒有 Numpad 就點右上角 Gizmo 的 −Y ／ +X ／ +Z 三顆球。手臂有沒有插進身體、頭有沒有浮在脖子上方，只有換角度才看得出來。

    零件之間稍微插進去是好事，不要追求剛好碰到——留縫隙在算圖時會看到破面。

  7. 遷移挑戰：自己決定並加上一個零件

    這一步沒有詳解可以展開。帽子、圍巾、天線、第三隻手都可以，重點是你自己決定要什麼、自己判斷用哪個 primitive 做得出來。

  8. 存到指定路徑

    路徑和檔名都要正確，之後的自檢會照這個路徑找檔案。

    展開詳細操作

    Ctrl+S，存到 work/p1/day02.blend。存好之後視窗標題列會顯示檔名。

05卡住了？

照症狀找，先自我診斷，答案在第二層。

新加的零件不見了，或跑到很遠的地方

新物件的落點取決於場景裡的一個小標記，而那個標記會被某個很容易誤按的操作移動。回想一下你剛剛在 Viewport 裡按了什麼。

還是不行，看答案

3D Cursor 被移走了——多半是按到 Shift+滑鼠右鍵。按 Shift+C 送回原點（視角會一起拉遠），或 Shift+S ▸ Cursor to World Origin 只動 Cursor。已經加歪的零件用 G 搬回來就好，不用刪掉重加。

複製出來的零件跟原件疊在一起，怎麼選都選到同一個

複製完成的瞬間，Blender 其實正在等你做一件事。想想你那時候按了什麼把它中斷掉。

還是不行，看答案

複製後 Blender 直接進入移動狀態，這時按 Esc 或右鍵會讓副本留在原地重疊。副本仍然存在且是被選取的，直接按 G 加軸向就能把它拉開。選不到想要的那一個時，去右上角 Outliner 點名稱來選最可靠。

叫零件往上，它卻往斜的方向跑

這個零件是不是被你轉過角度？如果是，「上」這個字對它和對世界來說已經不是同一個方向了。

還是不行，看答案

你用的是 Global 軸，但想要的是 Local。把軸鍵連按兩次即可：G Z Z 沿零件自己的 Z 軸移動。R 和 S 也適用同一個規則。

想選後面那個零件，怎麼點都選到前面的

你不一定要在 3D Viewport 裡點它。畫面上還有另一個地方列出了場景中的所有物件。

還是不行，看答案

右上角的 Outliner 會列出所有物件，點名稱就能選到被擋住的那個。另一個方法是在同一個位置連續點左鍵，Blender 會在重疊的物件之間輪流切換。建議順手把零件改成看得懂的名字（在 Outliner 上按兩下名稱），零件一多會差很多。

06常見錯誤

常見做法為什麼有問題改成
每個重複零件都重新 Add 一次兩邊的尺寸與角度很難調到一致，改設計時要改很多次做好一個再 Duplicate，副本天生就跟原件一樣
形狀不夠好看就想進 Edit Mode 改點今天的題目用 primitive 參數加 Transform 就夠了，太早進 Edit Mode 會把簡單的事變複雜用 S 調比例，或重加時在左下角 Add 面板調 Segments
覺得零件要合併成一個物件才算完成今天不需要合併，多個獨立物件同樣是一個完整模型保持各自獨立，在 Object Mode 排好位置就好
為了做得好看卡在細節上curriculum 明寫「不要追求漂亮」，今天驗的是安排零件的能力時間到了就存檔收工，醜沒有關係
